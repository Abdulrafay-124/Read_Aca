# Read_Aca
A  premium AI-enhanced Online Library for students and readers alike.
Made with modern technology stack.

# Planned Features
-	Product Listing: Dual-mode listing for both direct sales and short-term rentals.
-	Transactional System: A custom-built virtual wallet and internal ledger to facilitate secure payments and "Add to Cart" functionality.
-	Rental Management: A tracking module for rental durations (weeks/months) including automated damage-fee calculations.
-	In-app Messaging: A real-time communication channel for buyers and sellers to negotiate and track orders.
-	Account & Role Management: A unified account system where users can toggle between buyer and seller personas.
-	Recommendation Engine: A content-based filtering system that suggests books based on category and user browsing history.
